# Библиотека с готови промптове за маркетинг
## Копирайте и адаптирайте за вашия бизнес

---

## ТЕКСТОВИ ПРОМПТОВЕ

### 1. Facebook пост
```
Напиши 3 варианта на Facebook пост за [продукт/услуга], насочен към [аудитория].
Тон: [тон]. Включи CTA за [действие]. До [брой] думи.
```

**Пример за малък бизнес:**
```
Напиши 3 варианта на Facebook пост за фризьорски салон в Пловдив,
насочен към жени 25-45. Тон: приятелски и професионален. Промотирай
нова кератинова терапия с 20% отстъпка. Завърши с CTA за онлайн
резервация. До 100 думи.
```

**Пример за община:**
```
Напиши Facebook пост за Община Габрово, който информира гражданите
за нова онлайн услуга за издаване на удостоверение за настоящ адрес.
Тон: официален но достъпен. Аудитория: граждани 30-60 г.
Включи стъпките за ползване и завърши с линк към услугата. До 120 думи.
```

### 2. Instagram Content календар
```
Създай седмичен content календар за Instagram с 5 поста за [тип бизнес].
Включи хаштагове на български. За всеки пост посочи: тема, тип
(снимка/видео/карусел), текст и хаштагове.
```

### 3. Имейл кампания
```
Напиши имейл за промоция на [оферта]. Аудитория: [описание].
Subject line + текст до 200 думи. Тон: [тон]. Включи CTA бутон.
```

### 4. Анализ на данни
```
Анализирай тези данни от кампания: [копирай данните].
Дай 3 извода и 3 препоръки за подобрение.
Посочи кои формати работят най-добре и защо.
```

### 5. Tone of Voice гайд
```
Създай Tone of Voice гайд за [организация]. Ние сме [описание].
Аудиторията ни е [описание]. Дай примери за подходящ и неподходящ
тон в различни ситуации (социални мрежи, имейл, сайт).
```

### 6. Landing page текст
```
Напиши текст за landing page за [услуга]. Структура: заглавие,
подзаглавие, 3 ползи за клиента, testimonial цитат, CTA бутон.
Тон: [тон]. Аудитория: [описание].
```

### 7. Серия от публикации
```
Създай 5-дневна серия от публикации за [тема] за [бизнес тип].
Всеки пост трябва да надгражда предходния. Структура:
Ден 1: ангажиране, Ден 2: образование, Ден 3: социално доказателство,
Ден 4: оферта, Ден 5: спешност + CTA.
```

### 8. Blog статия
```
Напиши blog статия на тема "[тема]" за [аудитория]. Дължина: 800 думи.
Структура: въведение с hook, 3-5 подточки с подзаглавия, заключение
с CTA. Включи практически съвети и примери. SEO ключови думи: [думи].
```

## ВИЗУАЛНИ ПРОМПТОВЕ

### 1. Facebook банер
```
Създай банер за Facebook 1200x628px за [бизнес]. Стил: модерен и чист.
Цветове: [бранд цветове]. Текст: [промо текст]. Минималистичен дизайн.
```

**Пример за община:**
```
Създай банер за Facebook на Община Габрово. Тема: нова е-услуга за
удостоверения онлайн. Стил: официален но приветлив. Цветове: син и бял.
Включи икона на компютър и щастлив гражданин. Текст: "Без опашки —
онлайн за 5 минути". 1200x628px.
```

### 2. Продуктова снимка
```
Фотореалистична снимка на [продукт] на бял фон, студийно осветление,
перфектна за онлайн магазин, формат квадрат.
```

### 3. Инфографика
```
Инфографика за [тема], flat design стил, 3-4 стъпки с икони,
цветове: [цветове], вертикален формат за Instagram Story.
```

### 4. Илюстрация за община
```
Илюстрация за публикация на Община [име]: [тема на услугата],
приветлив стил, включи хора и дигитални устройства, формат 1:1.
```

### 5. Instagram Reel cover
```
Визия за Instagram Reel cover: [тема], ярки цветове, голям текст
"[заглавие]", фон с градиент, формат 9:16.
```

### 6. Социална визия с цитат
```
Визуална карта за Instagram с цитат: "[цитат]". Минималистичен дизайн,
[цвят] фон, бял текст, лого [бизнес] в долния десен ъгъл. 1080x1080px.
```

## СЪВЕТИ ЗА ПО-ДОБРИ РЕЗУЛТАТИ

1. **Бъдете конкретни** — колкото повече детайли, толкова по-добър резултат
2. **Итерирайте** — ако първият резултат не е перфектен, кажете какво да промени
3. **Задайте ограничения** — брой думи, формат, стил помагат за фокус
4. **Дайте контекст** — опишете бизнеса, аудиторията, целта
5. **Поискайте варианти** — "дай 3 варианта" е по-добре от "напиши един"
